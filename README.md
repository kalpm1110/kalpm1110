## Projects

### 🔗 [QRly — QR Analytics Platform](https://github.com/kalpm1110)
`Next.js · Redis · Supabase · AWS EC2`

A full-stack platform for dynamic QR generation, link management, and real-time scan analytics.
- Built a **Redis-based analytics pipeline** (in-memory counters + TTL + batched writes) → **90% faster queries**, lower DB load
- Deployed on **AWS EC2** with load balancing & reverse proxy for zero-downtime updates
- Live dashboard with scan timelines, device insights, link expiry, and performance tracking

---

`MongoDB · Node.js · React · Socket.io · Cloudinary`

- Real-time sync and chat via **Socket.io**
- Snapshot saving of sessions using **Cloudinary**
- Personalized user profiles for managing saved whiteboards
